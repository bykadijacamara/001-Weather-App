🌤️ Simple Weather App

This is a beginner-friendly weather application that fetches real-time weather data from the OpenWeatherMap API. You can search for any city and get the current temperature, humidity, wind speed, and a weather emoji to match the condition.

🚀 Features
	•	🔍 Search for any city to get live weather info.
	•	🕒 Background changes based on the time of day (morning, afternoon, evening, night).
	•	☁️ Dynamic weather emojis based on conditions (sunny, rainy, snowy, etc).
	•	⏳ Loader animation while data is fetched.
	•	❌ Error handling for empty input and city not found.
	•	🖱️ Keyboard support (pressing “Enter” triggers search).

🛠️ Technologies Used
	•	HTML, CSS, JavaScript
	•	OpenWeatherMap API


📦 Setup Instructions
	1.	Clone the repo
git clone https://github.com/your-username/weather-app.git
	2.	Open the index.html file in your browser
(or host it using Live Server if you’re using VS Code)
	3.	Done!
